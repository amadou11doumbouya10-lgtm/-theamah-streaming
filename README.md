# 🎬 Theamah+ — Plateforme de Streaming (VOD)

Application web de streaming type Netflix : plus de **600 000 films et séries** via l'API TMDB, en version française, **installable comme une app (PWA)** et **100 % front-end** (sans backend).

🔗 **Démo en ligne :** https://amadou11doumbouya10-lgtm.github.io/-theamah-streaming/

## ✨ Fonctionnalités

- 🎥 Catalogue massif (600K+ titres) via l'**API TMDB**
- 🇫🇷 Version française (VF) avec sélecteur de langue
- 📲 **PWA installable** (mobile & desktop) — service workers, mode hors-ligne
- ▶️ Lecteur vidéo intégré + reprise de lecture (« Continuer à regarder »)
- ⭐ Favoris, notes et bibliothèque personnelle (stockage local)
- 🗂️ Sections dynamiques : Tendances, Mieux notés, par genre, Séries…
- 📝 Sous-titres (SRT / VTT)
- 🛠️ Mode admin : ajout de contenu par fichier ou URL, avec métadonnées automatiques

## 🧱 Stack technique

`HTML5` · `JavaScript (ES6+)` · `API TMDB` · `PWA / Service Workers`

## 🚀 Lancer en local
